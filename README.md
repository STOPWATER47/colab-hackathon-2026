# Co-Lab 2026 해커톤 홈페이지

GitHub Pages에 올리는 **한 페이지 웹앱**입니다. 데이터·파일·로그인은 모두 **운영팀 구글 시트·드라이브(Apps Script)** 하나로 처리합니다. 회원가입·비밀번호는 없습니다.

## 화면 (모두 index.html 안에서 전환)
| 주소 | 내용 |
|---|---|
| index.html | 메인 (사진 + 대회 안내) |
| #/apply | 참가 신청 — 학생 / 멘토 / 심사위원 (이름, 영문 이름, 이메일, 학교·소속, 관심 분야) |
| #/login | 로그인 — 이메일로 6자리 인증코드 받기 (승인된 사람만) |
| #/my | 팀 · 제출 — 학생: 팀 만들기(팀장) · 모집 중인 팀에 합류 신청 · 결과물 제출 · 멘토링 기록 보기 / 멘토: 멘토링 입력 / 심사위원: 점수 입력 |
| #/board | 게시판 — 누구나 읽기, 로그인하면 글·댓글 작성, 운영팀 글은 공지로 위에 고정 |
| #/admin | 운영 관리 — 신청 승인·반려, 팀·제출, 멘토링, 심사 결과(비공개) |


## 흐름
1. 참가 신청 → 시트 `Users` 탭에 `pending`으로 저장
2. 운영팀이 운영 관리 화면에서 승인 (또는 시트의 status 칸을 `approved`로)
3. 승인된 이메일로 인증코드 로그인 (코드 10분 유효, 5번 틀리면 다시 받기, 1분에 한 번)
4. 팀장이 팀을 만들고, 팀원은 '모집 중인 팀'에서 합류 신청 → 팀장이 수락 (최대 4명)

## 데모 모드
`assets/config.js`의 `ENDPOINT`가 비어 있으면 데모 모드입니다. 데이터는 이 브라우저에만 저장되고, 인증코드는 메일 대신 화면에 보여 줍니다.
데모 이메일: admin@demo.kr(운영팀), team@demo.kr(팀 있음), solo@demo.kr(팀 없음), mentor@demo.kr, judge@demo.kr, new@demo.kr(승인 대기)

## 실제 연결 (한 번만)
1. 운영팀 구글 계정으로 새 스프레드시트 → 확장 프로그램 → Apps Script
2. `apps-script/Code.gs` 내용을 통째로 붙여넣고 저장
3. 프로젝트 설정 → 스크립트 속성: `ADMIN_EMAILS` = 운영팀 이메일(쉼표로 여러 개). 이 이메일은 신청 없이 바로 관리자로 로그인됩니다.
4. 편집기에서 `setup` 함수 한 번 실행 (권한 허용: 시트·드라이브·메일 보내기)
5. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: 모든 사용자 → 웹 앱 URL 복사
6. `assets/config.js`의 `ENDPOINT`에 붙여넣기 → GitHub에 올리면 끝

인증코드 메일은 운영팀 구글 계정 이름으로 나갑니다. 일반 Gmail은 하루 100통, 학교(Workspace) 계정은 하루 1,500통까지 보낼 수 있습니다.

## 수정할 때
- 처리 로직은 `assets/core.js` 하나입니다. 고친 뒤 `Code.gs` 위쪽 CORE 부분도 똑같이 바꿔 주세요.
- 심사 기준·제출 단계·팀 인원을 바꾸면 `config.js`와 `Code.gs` 위쪽 `CRITERIA`·`TIE`·`STAGES`·`TEAM_MAX`를 같이 맞춰 주세요.

## 폴더 구성
- `index.html` — 사이트 전체 (한 페이지)
- `assets/` — `style.css`(디자인), `app.js`(메뉴·언어·서버 연결), `views.js`(신청·로그인·팀·운영 화면), `core.js`(처리 로직), `config.js`(일정·심사 기준·설정), 아이콘·국기·가이드 그림
- `apps-script/Code.gs` — 구글 시트에 붙여 넣는 서버 코드

## 개인정보
- 비밀번호를 받지 않습니다. 인증코드와 로그인 토큰은 암호화(해시)해서 숨김 탭(`Codes`, `Sessions`)에 보관합니다.
- 시트는 링크 공유를 끄고 필요한 사람만 초대하세요. 행사 종료 후 시트와 드라이브 폴더를 삭제합니다.
- 제출 파일은 "링크가 있는 사용자 보기"로 공유되어 심사위원이 열 수 있습니다.
